# How to suggest changes

You do not need to touch this repository to improve the skill.

When you ask Claude for something the skill does not cover (a new format, a missing color or asset,
an unclear rule), Claude does its best within the brand rules and ends its answer with a short note:

```
Feedback for previo-brand skill
Request: …
Missing / unclear: …
What I did instead: …
Suggested change: …
```

Send that note to the skill author (Pavel Trnka). You can also write one yourself in the same shape
whenever something in an output does not look right. The author collects the notes and releases a
new version of the skill.
